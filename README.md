# SWAGFORUM FULL

Полноценная стартовая версия игрового форума для Render + PostgreSQL.

## Что есть

- регистрация и вход;
- безопасное хеширование паролей;
- сессии;
- профили пользователей;
- аватары по URL;
- группы и уровни 1–8;
- администраторы;
- категории и разделы;
- создание тем;
- ответы;
- закрепление/закрытие тем;
- удаление тем и сообщений для модераторов;
- поиск;
- список пользователей;
- уведомления;
- журнал действий администрации;
- адаптивная мобильная версия;
- PostgreSQL;
- health endpoint `/health`.

## Переменные Render

`DATABASE_URL` — строка подключения PostgreSQL.

`SESSION_SECRET` — длинный случайный секрет.

`ADMIN_USERNAME` — логин первого администратора.

`ADMIN_PASSWORD` — пароль первого администратора.

## Render

Build Command:
`npm install`

Start Command:
`npm start`

Создай PostgreSQL в Render и подключи `DATABASE_URL` к Web Service.

При первом запуске приложение автоматически создаст таблицы, категории и первого администратора.

## Важно

Это собственная реализация с похожей игровой форумной атмосферой, а не копия исходного кода чужого форума.
